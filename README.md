# Automation-for-sociale-media

24/7 AI comment-reply system for Mosiquaire (custom mosquito nets) — self-hosted n8n on a
VPS, replies to YouTube/Instagram/Facebook comments in the owner's voice, routes sensitive
messages to Telegram for approval.

**Start here: [`GUIDE.md`](./GUIDE.md)** — current state, what's done, and what's still
needed from you. `CLAUDE-CODE-MASTER-PROMPT.md` is the original build plan this package
follows.
